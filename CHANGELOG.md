# Changelog

All notable user-visible changes to the ChatGPT Next Web TOS application package.

## 2.16.1-1 — 2026-11-11

### Added
- First release. ChatGPT Next Web (`yidadaa/chatgpt-next-web:v2.16.1`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8072 and running
  as a non-root user (1000:1000).
